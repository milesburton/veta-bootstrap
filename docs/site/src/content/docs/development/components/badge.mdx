A small inline pill for showing status: success, error, warning, info, or neutral. Reads its colours from the semantic tokens documented in the [style guide](../../style-guide/), so it stays in sync if those change.

This is the example primitive the bootstrap ships with, to prove the live-import pattern works end to end before you add your project's real components.

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `"success" \| "error" \| "warning" \| "info" \| "neutral"` | (none) | Required. Drives the badge's colour. |
| `children` | `React.ReactNode` | (none) | Required. The badge's label. |
| `className` | `string` | `""` | Extra Tailwind classes. |

## Import

```tsx
import { Badge } from "@app/frontend/components/Badge";

<Badge status="success">Deployed</Badge>
```
